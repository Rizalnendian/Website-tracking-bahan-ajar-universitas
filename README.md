# Website-tracking-bahan-ajar-universitas 📚

A comprehensive web application designed for the Universitas Terbuka to manage and track the distribution of educational materials. This system, SITTA (Sistem Informasi Tiras dan Transaksi Bahan Ajar), facilitates efficient handling of book orders, inventory management, and delivery tracking for UT-Daerah (Regional UT branches).

## 🌟 Features

*   **User Authentication:** Secure login system for UT-Daerah administrators.
*   **Dashboard Overview:** Provides a summary of key metrics like total learning materials, active delivery orders, and low stock alerts.
*   **Inventory Management:** Allows detailed tracking of learning materials, including stock levels, pricing, and safety stock.
*   **Delivery Order (DO) Management:** Enables the creation and management of delivery orders for students.
*   **Real-time Tracking:** Tracks the status and journey of delivery orders from dispatch to arrival.
*   **Reporting:** Generates reports on DO progress, learning material summaries, and transaction history.
*   **Responsive Design:** User-friendly interface adaptable to various screen sizes.
*   **Demo Account:** Easy access for trying out the system with pre-configured credentials.

## 📚 Usage

### Login

1.  Open the application in your browser.
2.  Navigate to the login page (`index.html`).
3.  Enter your registered email and password.
4.  Click the 'Masuk' button.

**Demo Account:**
*   Email: `admin@ut.ac.id`

### Key Workflows

*   **Managing Inventory:**
    *   Navigate to the 'Informasi Bahan Ajar' page (`stok.html`).
    *   Use filters to find specific materials.
    *   Add new materials or edit existing ones.
    *   Monitor stock levels and reorder status.

*   **Creating and Tracking Delivery Orders:**
    *   Navigate to the 'Tracking Pengiriman' page (`tracking.html`).
    *   Fill out the 'Buat Pengajuan Delivery Order' form with student and package details.
    *   Submit the form to create a new Delivery Order (DO).
    *   Use the 'Lacak Status Pengiriman' section to search for a DO by its number and view its progress.

*   **Dashboard Navigation:**
    *   The dashboard (`dashboard.html`) provides quick access to different sections via the sidebar.
    *   View summary statistics and recent activities.
